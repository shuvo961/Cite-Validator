Security

Security Notes

The MVP includes practical safeguards for local and public deployment, with clear production upgrade paths.

Current safeguards

The app uses HTTP-only sessions, password hashing for hidden owner/admin access, security headers, basic API rate limiting, hidden owner admin route, and admin-only monitoring endpoints.

Google login

Google OAuth is supported when `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, and `APP_BASE_URL` are configured.

Production recommendations

Use HTTPS, PostgreSQL, Redis-backed rate limiting/cache, automated backups, external monitoring, and a secure secret manager before high-traffic public launch.
